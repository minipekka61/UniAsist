# UniAsist Uygulama Planı

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Belgelerdeki UniAsist tasarımını (FR-01…28, IK-01…35, UC-01…24) çalışan bir Flask uygulaması olarak kodlamak.

**Architecture:** UML entity–boundary–control katmanları Python paketlerine 1:1 taşınır: `uniasist/entity.py` (varlıklar), `uniasist/depo/` (SQLite depoları), `uniasist/servis/` (iş kurallarını uygulayan servisler), `uniasist/yapayzeka/` (LLM arayüzü + gerçeklemeler), `uniasist/ekran/` (Flask blueprint'leri). RAG: parçalama → gömme → kosinüs arama (eşik 0,60) → LLM yanıtı `BILGI_YOK` işaretiyle doğrulanır → SSE akışı.

**Tech Stack:** Python 3.13, Flask, sqlite3 (stdlib), pypdf, requests, pytest. Şablonlar Jinja2 + vanilla JS/CSS.

**Spec:** `docs/superpowers/specs/2026-10-25-uniasist-design.md` (kaynak PDF metinleri: `../../../*.txt`)
